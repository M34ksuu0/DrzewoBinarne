# Drzewo binarne

Program w języku C++ przedstawia implementację drzewa binarnego wyszukiwania (BST).

Działanie programu

Program:

    pobiera od użytkownika liczbę elementów,

    umożliwia wprowadzenie kolejnych liczb,

    dodaje liczby do drzewa w odpowiednich miejscach,

    wyświetla zawartość drzewa.

Jeżeli dodawana liczba jest mniejsza od wartości w aktualnym węźle, zostaje umieszczona po lewej stronie. W przeciwnym przypadku trafia na prawą stronę.

Wykorzystane elementy

W programie zastosowano:

    strukturę Lisc przechowującą dane węzła,

    klasę drzewo,

    wskaźniki,

    dynamiczne tworzenie węzłów,

    rekurencję.

Program jest prostym przykładem działania drzewa binarnego oraz operacji dodawania elementów.
